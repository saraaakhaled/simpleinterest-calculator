# Simple Interest Calculator

A simple calculator that calculates the simple interest based on the principal amount, interest rate, and time period.

## Formula

**Simple Interest = (P × R × T) / 100**

Where:

* **P** = Principal amount
* **R** = Rate of interest per year
* **T** = Time period in years

## Example

If:

* Principal = $1000
* Rate = 5%
* Time = 2 years

Then:

**Simple Interest = (1000 × 5 × 2) / 100 = $100**

## Features

* Calculates simple interest
* Easy to use
* Takes principal, rate, and time as inputs
* Displays the calculated interest
